# 雀カルテ テストケース一覧

ユーザーが操作しうるケースを網羅するためのテストケース一覧。

- **方法**: 自動 = ヘッドレスブラウザで自動テスト可能 / 実機 = スマホ実機での確認が必要（指の操作感・共有シート・クリップボード等） / 外部 = Googleログイン・Firestoreなど外部サービスが必要
- **優先度**: 高 = データ消失・操作不能につながる / 中 = 表示崩れ・誤表示 / 低 = 見た目の細部
- ✅ 印は、これまでの自動テスト（e2e.js）で確認済みのもの
